# English-learning

一个面向中文用户的英语学习静态网站，聚焦英语基础能力、AI 高频术语和 GitHub 常见表达。

## 网站内容

- 首页 Hero：展示学习目标、行动入口和今日进度。
- 学习路线：覆盖 Listening、Speaking、Reading、Writing 四个核心模块。
- 高频词汇：收录 repository、issue、pull request、prompt、workflow、deployment 等技术英语词条。
- 互动练习：通过选择题即时反馈，帮助记忆常见英文术语。
- 每日计划：提供 20 分钟轻量学习流程，便于长期坚持。

## 本地预览

直接用浏览器打开 `index.html`，或启动一个本地静态服务：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 原始词汇示例

- `repository`：仓库
- `issue`：议题（用于记录 Bug、建议或待办事项）
- `pull request`：拉取请求（PR，提交代码合并申请或进行代码审查）
- `Discussions`：讨论（用于项目相关的开放性交流和问答）
- `Projects`：项目（用于规划开发进度和任务看板管理）
